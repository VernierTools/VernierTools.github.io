Instrument Channel Mute

A script for Fender Studio Pro 8 that makes muting an instrument track silence the instrument itself, not just its MIDI. It links each track's mute with its instrument channel in the Console, and adds a mute command that works whichever view has focus.

Features
  • Mute Link: track mute silences the instrumentNormally an instrument track's M button only mutes its MIDI, so the instrument keeps sounding. With Mute Link, the track's M and its instrument channel's M in the Console follow each other automatically, in both directions. Tracks are matched to instruments by their actual connections, so renaming tracks is fine.
  • Works with shared instrumentsWhen several tracks play one instrument, muting one track leaves the others sounding; the instrument channel is muted only once all of those tracks are muted. Muting the instrument channel in the Console mutes all of its tracks, and unmuting it puts each track back the way it was.
  • A mute command for any focus"Toggle Instrument Channel Mute" mutes or unmutes the instrument channel of the selected tracks, the same way whether the Arrange view or the Console has focus. Assign it a key, such as one on the numeric keypad. With several tracks selected, it mutes them all if any is unmuted, and unmutes them all otherwise. For audio tracks it mutes the track's own channel.
  • Switch the link off, or probe for reports"Toggle Instrument Mute Link" turns Mute Link on or off and shows the new state (it starts on). "Instrument Channel Mute Probe" shows what the script sees about the selected tracks and channels, to help when something doesn't work.
Requirements & notes

Requirements
Tested only with Fender Studio Pro 8.2.0 (Build 114903) on macOS with Apple Silicon. Not tested on Studio One 6 or 7, Windows or Intel Macs. The install steps are for macOS.

Good to know
Mute Link doesn't fix mismatches that already exist when a song opens; it starts following once you press an M button. A change can take up to about 0.1 seconds to show. Extra outputs of multi-output instruments (such as "Stereo 2") aren't linked; mute them in the Console as before. Tracks that aren't connected to an instrument, such as the chord track, are left alone. How it behaves together with Undo (⌘Z) hasn't been checked yet.

Install (macOS)
  1. Download the .zip file above and unzip it.
  2. Quit Studio Pro.
  3. In Finder, choose Go ▸ Go to Folder… (⌘⇧G), paste this path and press Return:~/Library/Application Support/Fender/Studio Pro 8/Extensions/
  4. Copy the "local.instrumentchannelmute.mac" folder from the unzipped files into that folder, as is. It must contain metainfo.xml, installdata.xml and a Scripts folder with instrument-channel-mute.package.
  5. Start Studio Pro. Mute Link starts working right away. To use the command, search for "Instrument Channel Mute" in Keyboard Shortcuts and assign a key to "Toggle Instrument Channel Mute".

Updating
Quit Studio Pro and replace the whole "local.instrumentchannelmute.mac" folder in the Extensions folder with the new one.

Uninstall
Quit Studio Pro and delete the "local.instrumentchannelmute.mac" folder from the Extensions folder above.
