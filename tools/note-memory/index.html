Note Memory

Makes notes you place by clicking in the Fender Studio Pro 8 piano roll take the length and velocity of the last note you touched.

Read before installing
  • Unofficial, no warranty. Not made or supported by Fender or PreSonus. It uses undocumented internal features of Studio Pro.
  • Never put it inside the app. Placing files inside "Studio Pro 8.app" breaks its signature so it won't start, and you will have to reinstall Studio Pro. Use only the Extensions folder in the install steps.
  • "Install from File" won't work. It isn't a signed .install file. Copy the folder by hand.
  • It isn't signed. It runs with the same rights as Studio Pro, in the background from launch. It reads piano roll notes and settings, changes note length and velocity, runs Undo and Redo, and shows dialogs; it doesn't access files or the network. Don't use copies from other sources.
  • Updates may break it. A Studio Pro update may stop it working, or stop unsigned extensions from loading.
  • Check the code first. Any downloaded script could be malicious, this one included. Read the code in the source folder of the .zip, or have an AI assistant check it for security problems, before installing.

Features
  • Length and velocity memoryA note placed by clicking normally gets the Note Length setting (such as 1/16) and the default velocity. Note Memory remembers the length and velocity of the note you last selected, drew or changed, and applies them to the next note you place by clicking. Odd lengths, such as dotted or dragged ones, carry over as is. Pitch and position stay where you clicked.
  • Only clicked notesIt rewrites a note only when exactly one note is added and its length equals the Note Length setting. A note drawn by dragging is left as drawn, and its length is remembered instead.
  • One-step UndoPlacing and rewriting a note are two steps in the history, but one ⌘Z removes the note and one ⌘⇧Z brings it back rewritten.
  • Commands"Toggle Note Memory" turns it on or off (on at launch). "Note Memory Status" shows what the script remembers and has done, for problem reports. "Note Memory Check" is used internally; don't assign a key to it.
Requirements & notes

Requirements
Tested only with Studio Pro 8.2.0 on macOS (Apple Silicon). Untested on Windows, Intel Macs, Studio One 6/7 and the Drum Editor.

Good to know
The rewrite happens about 0.03 s after the click, so the original length may flash briefly. A dragged note that happens to match the Note Length setting exactly is treated as clicked. Nothing happens if the length can't be read from the Note Length setting (such as unusual tuplets). One-step Undo covers the last 50 rewritten notes and resets when you switch songs; older ones, or pressing ⌘Z quickly (within 0.2 s), may take two presses. It doesn't work while Note Memory is off.

Install (macOS)
  1. Download and unzip the .zip file above.
  2. Quit Studio Pro.
  3. In Finder, choose Go ▸ Go to Folder… (⌘⇧G) and open:~/Library/Application Support/Fender/Studio Pro 8/Extensions/
  4. Copy the "local.notememory.mac" folder into it, as is.
  5. Start Studio Pro. Note Memory is active. To switch it on and off by key, assign one to "Toggle Note Memory" in Keyboard Shortcuts.

Update
Quit Studio Pro and replace the folder with the new one.

Uninstall
Quit Studio Pro and delete the folder.
