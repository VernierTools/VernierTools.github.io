Blender add-on

Set Origin to Selected

Move an object's origin to the selected vertices, edges or faces without leaving Edit Mode.

Features
  • One button in Edit ModeA "Set Origin" button appears in the 3D Viewport header only while you edit a mesh.
  • Uses the selection's centerThe origin moves to the median of the selected vertices, edges and faces. The geometry stays where it is.
  • Leaves everything as it wasYou stay in Edit Mode, and the 3D cursor, selection and active object are restored. In multi-object editing only the active object changes.
Requirements & notes

Requirements
Requires Blender 4.5 or later. Pure Python, so it should run on Windows, macOS and Linux; tested on macOS with Blender 5.2.

Good to know
If the mesh is shared with other objects (linked duplicates), their geometry moves too, because they use the same mesh. One undo step reverts it.

Install
  1. Download the .zip file on the right. Don't unzip it.
  2. In Blender, open Edit ▸ Preferences ▸ Get Extensions.
  3. Open the ⌄ menu at the top-right, choose "Install from Disk…", then pick the .zip file. (Dragging the .zip into the Blender window also works.)
  4. Enter Edit Mode on a mesh and find "Set Origin" in the 3D Viewport header.
