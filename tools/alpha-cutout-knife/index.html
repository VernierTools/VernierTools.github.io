Blender add-on

Alpha Cutout Knife

Cut a mesh along a texture's alpha edge and delete the transparent faces.

Features
  • A clean cut lineEdges are split exactly where the alpha edge crosses them, and only the faces it passes through are rebuilt. Temporary helper edges are dissolved afterwards.
  • Finds the right textureFollows each material's nodes back from the Alpha input, through reroutes and node groups. Slots without an alpha texture are left untouched.
  • Rig-safeVertex group weights and shape key positions are carried over to the new vertices, so armatures and shape keys keep working.
  • Object or Edit ModeRuns on the active mesh in either mode, and every setting can be tweaked afterwards in the Adjust Last Operation panel.
Requirements & notes

Requirements
Requires Blender 4.2 or later. Pure Python, so it should run on Windows, macOS and Linux; tested on macOS with Blender 5.2.

Good to know
The cut follows the active UV map. Mapping or vector nodes between the UVs and the image (scale, offset, rotation) are not taken into account. Images whose Alpha Mode is None have no alpha to read. If a shape key other than Basis is active in Edit Mode, the cut is refused; select Basis first.

Install
  1. Download the .zip file on the right. Don't unzip it.
  2. In Blender, open Edit ▸ Preferences ▸ Get Extensions.
  3. Open the ⌄ menu at the top-right, choose "Install from Disk…", then pick the .zip file. (Dragging the .zip into the Blender window also works.)
  4. Find it in the 3D Viewport ▸ Sidebar (N) ▸ "Alpha Cut" tab.
