Blender add-on

Material Users

See in the Shader Editor header how many objects use the material you are editing, and jump to any of them.

Features
  • Count in the headerThe Shader Editor header shows how many objects use the material being edited.
  • List of usersClick the number to see those objects. Objects outside the current view layer and hidden objects are marked.
  • Jump to an objectClick an object to make it active, with the same material still shown in the editor.
Requirements & notes

Requirements
Requires Blender 4.5 or later. Pure Python, so it should run on Windows, macOS and Linux; tested on macOS with Blender 5.2.

Good to know
Objects are counted, including ones that get the material through their mesh. Jumping to an object works in Object Mode and only for objects in the current view layer.

Install
  1. Download the .zip file on the right. Don't unzip it.
  2. In Blender, open Edit ▸ Preferences ▸ Get Extensions.
  3. Open the ⌄ menu at the top-right, choose "Install from Disk…", then pick the .zip file. (Dragging the .zip into the Blender window also works.)
  4. Open a material in the Shader Editor; the user count appears in the header.
