Blender add-on

Duplicate to Instance

Find objects with identical meshes and make them share one mesh to save memory.

Features
  • Linked duplicates in one clickObjects whose mesh data is identical are switched to share a single mesh, like Alt+D duplicates. The scene looks exactly the same, but memory use and file size go down.
  • Only true duplicatesMeshes must match in vertex positions, faces, UV maps, materials and vertex-group weights. Anything different is left alone.
  • Objects stay as they areOnly the mesh data is swapped, so each object keeps its name, transform, modifiers, parent, animation and custom properties.
Requirements & notes

Requirements
Requires Blender 4.2 or later. Pure Python, so it should run on Windows, macOS and Linux; tested on macOS with Blender 5.2.

Good to know
Copies whose transform has been applied (so the vertices themselves differ) are not detected. Meshes with shape keys are skipped. Use Selected to limit the scope; one undo step reverts it.

Install
  1. Download the .zip file on the right. Don't unzip it.
  2. In Blender, open Edit ▸ Preferences ▸ Get Extensions.
  3. Open the ⌄ menu at the top-right, choose "Install from Disk…", then pick the .zip file. (Dragging the .zip into the Blender window also works.)
  4. Find it in the 3D Viewport ▸ Object menu, or the Sidebar (N) ▸ "Instance" tab.
