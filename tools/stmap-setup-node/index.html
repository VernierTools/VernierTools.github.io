Blender add-on

STMap Setup Node

Instantly apply STMaps in Blender's Compositor with a single click — no more manually linking Separate, Combine, and Map UV nodes by hand.

Features

Adds a dedicated panel to the Compositor's N-panel (Sidebar), so you never have to build an STMap node chain by hand again:

  • Create STMap Nodes — builds a complete template (Input Footage, STMap chain, Map UV, Composite, and Viewer) in one click.
  • Add STMap Warp (no output) — drops just the STMap chain and Map UV node at your 2D cursor, safe to paste into an existing complex tree.
  • Load STMap (Non-Color) — loads your STMap image and automatically forces its colorspace to Non-Color, preventing distortion from incorrect sRGB settings.
  • Set STMap to Non-Color — select any existing image node and force its colorspace to Non-Color in one click.

V-Flip (green channel inversion) and quality settings can be toggled in the F9 (Redo) panel right after clicking a creation button.

Compatibility
  • Blender 4.5 and 5.x.
  • Fully compatible with the new Blender 5.0 compositor system.
Install
  1. Download the .zip file on the right.
  2. In Blender, open Edit ▸ Preferences ▸ Add-ons.
  3. Click "Install…" (or the ▾ menu ▸ "Install from Disk…"), then pick the .zip file.
  4. Turn the add-on on with its checkbox. A new "STMap" tab appears in the Compositor's Sidebar (N-panel).
