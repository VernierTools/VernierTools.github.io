Using it in Blender / Nuke
  • Blender: set the Image node's color space to Non-Color.
  • Blender’s Map UV treats Blue as a validity mask, so “Blue = 1” is on by default. Nuke’s STMap ignores Blue, so it does no harm there.
  • Blender 5.0+: set Map UV interpolation to Bicubic or Bilinear.
  • Blender: with overscan, set the render resolution to the output size shown on the right, or the extra area is cropped. Overscan is added evenly on both sides so the frame stays centered.
  • Pixel-centered, bottom-left origin — the same convention as Nuke's STMap. Overscan is stored as the EXR data window (Nuke: bbox).
  • Blender's own Movie Distortion node can land up to 0.5 px off on one axis when its expanded frame has an odd size. This tool follows the lens formula exactly.
