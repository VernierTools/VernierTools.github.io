Using it in Blender
  • Set the Image node's color space to Non-Color.
  • Blue is written as 1.0, so it plugs straight into Map UV.
  • In Blender 5.0+, set Map UV interpolation to Bicubic or Bilinear.
  • Coordinates are pixel-centered with a bottom-left origin — the same convention as Nuke's STMap.
