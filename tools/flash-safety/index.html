ポリゴンショック・リスクチェッカー

閃光（輝度・赤）の検出、5基準（NHK・民放連 / ITU-R / Ofcom / WCAG 2.3.1 / WCAG 2.3.2）と参考1件（2024年提案）の並列判定、空間パターン（縞模様）の参考検出、タイムライン表示、プレビュープレイヤーが動作します。HDR映像には対応しておらず、検出した場合は解析を行いません。判定結果は参考用であり、医療・認証目的には使用できません。実機での網羅的な動作確認が完了していないため、実験的な位置づけとしています。

本ツールは一次チェック用の参考ツールであり、医療機器でも適合認証ツールでもありません。判定精度は100%ではなく、SDR動画のみに対応しています。最終的な安全性の判断は利用者自身の責任で行ってください。

判定
警告
    本ツールは参考用であり、医療機器でも適合認証でもありません。放送・映画・ゲーム等の商用制作物の適合確認には Harding FPA 等の認証ツールをご利用ください。基準に適合していても、すべての光感受性の方の発作を防げるわけではありません。
    プレビュー
    この判定の前提
    • SDR・ピーク白 200 cd/m² を前提とした推定値です。実際の画面輝度は測定していません。
    • 面積の免除は基準ごとに異なります（放送系＝画面の1/4超で対象 / WCAG 2.3.1＝任意の10度視野の25%超で対象 / WCAG 2.3.2は面積による免除なし）。 統合スコアは出しません。
    • ソースのfpsの半分（ナイキスト周波数）を超える速さの点滅は原理的に検証できません（30fpsなら15Hzまで）。
    • 赤の判定は色差が輝度の1/4解像度しかないため、輝度の判定より精度が落ちます。
    • ゲーム等のインタラクティブな映像は、録画した1つの経路しか評価できません。
    • 規格は「画面上の一点で明暗が入れ替わること」を点滅と定義します。そのため、点滅の演出がなくても、細かい模様の上をカメラが動く、被写体が縞の前を横切る、カット割りが速いといった映像でも遷移が計上されます（WCAGの微細パターン例外は適用済み）。
    • WCAG 2.3.2（AAA）は規格自体が極めて厳しく、W3Cが「単一の画素の点滅でも違反」と定めています。ここでの抵触は、必ずしも実用上の危険を意味しません。
    • 「想定再生速度」は、動画プレイヤーが全フレームをそのまま高速再生する前提の近似です。実際のプレイヤーが高倍速でフレームを間引く場合、体感される点滅とは異なることがあります。
    • 「検出なし」は安全の保証ではありません。 現行のガイドライン自体、感受性のある方の全員を保護できるわけではありません。
