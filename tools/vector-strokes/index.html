Blender add-on Beta

Vector Strokes (Image Editor)

Draw editable vector shapes, text and paint layers in the Image Editor, and write them into the image without touching the original.

Features
  • Non-destructiveThe original image stays as the bottom layer. Shapes, text and effects stay editable, and the result is written into the image's pixels, so materials and the 3D Viewport use it like any other image.
  • Familiar drawing toolsSelect, Pen, Pencil (freehand fitted to curves), Shape (rectangle, ellipse, polygon, star) and Text tools in the toolbar. Fills and strokes with solid colors or linear and radial gradients, corner rounding and Pathfinder operations.
  • Layers like an image editorLayers, groups, blend modes, layer masks, clipping masks and adjustment layers. Paint layers let you paint with Blender's brushes, including from the 3D Viewport.
  • Text that stays textPoint, area and on-path text, vertical writing and kerning, using the fonts installed on your computer. Text can be turned into outlines.
  • Effects, import and exportDrop shadow, blur, glow and grain. Import SVG as editable shapes, and export SVG or PDF.
Requirements & notes

Requirements
Requires Blender 5.2 or later on macOS with Apple Silicon or on Windows (x64). Each OS has its own download, because the add-on includes the Skia graphics library built for it. Intel Macs and Linux are not supported. Tested on macOS (Apple Silicon) with Blender 5.2.

Good to know
This is a beta: things may still change, and saving often is a good idea. The add-on's UI is in Japanese.

Install
  1. Download the .zip file for your OS on the right. Don't unzip it.
  2. In Blender, open Edit ▸ Preferences ▸ Get Extensions.
  3. Open the ⌄ menu at the top-right, choose "Install from Disk…", then pick the .zip file. (Dragging the .zip into the Blender window also works.)
  4. Open an image in the Image Editor, pick a vector tool in the toolbar or open the sidebar (N) ▸ "Vector" tab, and click the canvas to start.
