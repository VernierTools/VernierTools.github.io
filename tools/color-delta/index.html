Color difference (HSV / RGB)

Set two colors to see how far to move H, S, V or R, G, B to turn the first into the second.

Good to know
  • The values are amounts to add to the number fields of a color picker: S and V move in percentage points (40% → 54% is +14%), not by a ratio.
  • Hue goes round a circle, so the shorter way round is shown (within ±180°). The other way is shown underneath.
  • On a gray, black or white color the hue (and on black also the saturation) has no effect, so any value works.
  • The result is exact for this one color. The same shift applied to a whole image moves other colors differently, and some will clip.
  • HSV is not HSL: both call S “saturation”, but they are calculated differently, so check which one your software uses.
