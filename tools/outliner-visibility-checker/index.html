Blender add-on

Outliner Visibility Checker

Find objects whose viewport visibility and render visibility don't match.

Features
  • Count in the Outliner headerA button at the start of the Outliner header shows how many objects have the eye and the camera set differently. It turns red while any remain and updates as you toggle visibility.
  • Two clear listsClick the button to see objects that are hidden in the viewport but still render, and objects that are visible but won't render.
  • One-click fixesEach row has buttons to turn the eye or the camera on or off, and clicking a visible object's name selects it.
Requirements & notes

Requirements
Requires Blender 5.2 or later. Pure Python, so it should run on Windows, macOS and Linux; tested on macOS with Blender 5.2.

Good to know
Only each object's own eye (Hide in Viewport) and camera (Disable in Renders) toggles are compared. Visibility inherited from collections, and the monitor toggle (Disable in Viewports), are not counted. Objects hidden in the viewport can't be selected until you turn their eye back on.

Install
  1. Download the .zip file on the right. Don't unzip it.
  2. In Blender, open Edit ▸ Preferences ▸ Get Extensions.
  3. Open the ⌄ menu at the top-right, choose "Install from Disk…", then pick the .zip file. (Dragging the .zip into the Blender window also works.)
  4. Find the button at the left end of the Outliner header.
